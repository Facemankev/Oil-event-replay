# EVT · Event library

**Status:** Provisional. Everything below is a starting point for Dad to
rewrite. · **Section owner:** not yet chosen

**Goal (provisional):** A list of past events, each with its date, type, short description and a source, so they can be searched and matched.

**Exists today:** Seven oil events in `data/events.js` and the Brexit referendum in `data/research-data.js`. Other event types are catalogued in the lab but have no prices.

**Depends on:** Nothing. This is a foundation.
