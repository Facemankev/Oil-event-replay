# DATA-FREE-1: zero-charge data and the complete research process

Issue #40, on draft #39; coordinated with LIVE-1 #37. **Free data only.**
No signup, subscription, billing trial, paid API route, key request or charge.
This working bounded demonstration connects event ingestion, deterministic
detection, prior-event matching, dated price/peer checks, three answers and an
observation-only SQLite journal. No broker, account mutation or order exists.

The new optional page follows Brendan's **Gold × Desk** tokens and the existing
three answers. Its static examples are generated by the actual Python pipeline;
they do not call market APIs from the browser or change a practice account.
The original application, sources, historical prices and public previews remain
unchanged. The copied `design.css` is byte-identical to the house stylesheet.

Actual bounded anonymous HTTP event ingestion, using a new output path:

```sh
python3 -m free_pilot run --case nvidia_board --fetch-event --journal work/free-pilot/http-session --output work/free-pilot/new-http-observation.json
```

This fetches **a pinned public historical research catalog**, not a fresh original
issuer RSS release. Actual receipt time is recorded now; it is never backdated
into the original event. A cooldown/failed request remains unavailable and never
silently becomes a successful feed. One controlled successful run is recorded in
[OBSERVATIONS.json](OBSERVATIONS.json), with HTTP body fingerprint and local
request-through-observation timing. This is not publication-to-useful-alert
latency or an operating SLA. There is no continuous monitor or external alert.

## Actual data connected

The separate `work/free-pilot/history.sqlite` database imports **27,210 primary
observation rows: 26,074 numeric and 1,136 explicit blank/ND cells**. Repeat import
adds **zero** observations and reuses all **51** historical events. It uses the
safe, versioned HIST-1 database and retains older dataset versions.

- Existing EIA Brent/WTI: **10,394** numeric primary references, unchanged.
- Existing Fed GBP/USD: **5,224** numeric primary references, unchanged.
- New Fed EUR/USD and USD/JPY: **10,456** numeric observations and **434 ND**,
  2 January 2006 through 13 November 2026. Every weekday is captured; no missing
  section is turned into an invented price or a holiday explanation.
- The existing **66 secondary equity/index candidate rows** remain separate from
  primary prices. The parent equity/calendar engine supplies the Nvidia/peer
  context; agreement does not establish independent upstreams, adjustment factors
  or exchange prints. No extra raw secondary price CSV is published.
- The 13 HIST-1 reported session reactions and three corporate reference pairs
  remain reporting/reference evidence, not substituted daily series. Gold and
  pharma daily quote coverage is still incomplete.

[COVERAGE.json](COVERAGE.json) separates those evidence types. EUR/USD is **USD
per EUR**; USD/JPY is **JPY per USD**. A positive USD/JPY move does not mean yen
strengthened. GBP conversion retains the inherited `USD price / USD per GBP`
formula, using exact-date rates without forward fill or interpolation.

The two new snapshots were obtained from visible **official Fed tables through
the supported web reader**. Their complete normalized CSVs have byte fingerprints,
printed-date locators, units and capture metadata in `sources/manifest.json`.
They are not original HTTP bytes or evidence of original historical availability.
Direct refresh in this executor still receives a network-policy 403; these
separate access channels are not conflated.

The complete earlier historical decision is sealed **before** reading subsequent
price reactions. Later measurements live in separate fields. Tests mutate future

current capture time and scheduled session boundaries remain distinct. A daily
close is never relabelled as an intraday print. Selected corpus/case results do
not establish causal ripples, forecast probabilities or point-in-time-safe returns.

## Free-provider adapters and limitations

[providers.json](providers.json) records checked official documentation, free
quotas, terms and actual access. Advertised free tiers are **not connections**:

- EIA/Fed government numerical tables permit attributed reuse. Retained snapshots
  work; anonymous refresh adapters require ordinary permitted access to those hosts.
- Stooq displayed a browser challenge in the reader; the direct probe was 403.
  It was not bypassed. CSV normalization is tested with explicit synthetic fixtures;
  terms/adjustment uncertainty cannot become public quote permission.
- FRED has series-specific rights. Its former LBMA gold data were removed and
  S&P reproduction is restricted. The bounded Nasdaq CSV probe was policy-blocked.
- Alpha Vantage advertises 25 free requests/day, but its daily-adjusted function
  is explicitly premium. No key or premium/demo-key request was made.
- Twelve Data Basic advertises 8 credits/minute and 800/day, with internal
  non-display usage. Public redistribution and paid corporate-action endpoints
  are not assumed to be free.
- EODHD advertises a zero-cost sandbox with 20 calls/day and 20 requests/minute;
  exact history/redistribution entitlements remain unverified. No account exists.
- Yahoo returned 429 in the supported reader; no retry or alternate scraping path
  was attempted. Issuer/regulator facts are reused with attribution; original
  fresh financial feeds are not claimed as connected.

Only fixed anonymous GET endpoints are callable. Keyed providers have no enabled
route. No credential is read or written. Single bounded requests use inherited TLS
and proxy settings, no redirect/proxy workaround, a 60-second minimum reservation,
conditional ETag and 403/429/server/clock failure backoff. Error/challenge bodies
are not retained as price data. Private raw catalog cache is under ignored `work/`
and excluded from publication. Observation decisions are deduplicated without
refreshing their first record time; the journal refuses a Buy payload.

Optional primary-source refresh writes only a **new** local snapshot for review:

```sh
python3 -m free_pilot capture --source fed_eurusd --output-directory work/free-pilot/new-primary-capture
```

The capture is intentionally bounded to the documented research range. It does
not overwrite the pinned snapshot, canonical database or PR #19 reconciliation.
All output paths must be new and inside `work/`.
